## Why these TechDocs still help

The upstream docs are rich, but they are organized for the repo's own publishing stack. The `docs/techdocs/` pages and top-level `mkdocs.yml` created for this repository provide a clean RHDH entrypoint so the same codebase can be browsed through TechDocs.
